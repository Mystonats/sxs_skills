# Sword X Staff — Skill Wiki

A searchable reference for every skill in **Sword X Staff**: all 328 skills
across the 26 professions and 7 class-change tiers, with icon, rarity,
element, type and full effect text — plus the grid diagram showing an active
skill's range and area of effect.

Available in **English and German**.

## Read it online

<https://mystonats.github.io/sxs_skills/>

## What it does

- **Look up any skill** by name, effect text or keyword.
- **Filter** by class, tier, active/passive, rarity, element and tag.
- **Range and AoE diagrams** for active skills, drawn on the game's own grid.
- **Keyword explanations** (Lifesteal, Shield, …) inline with the skill text.
- **English / German toggle** — every skill name and description exists in
  both languages.

Skills only. This is a focused reference, not a full wiki — no calculators,
builders or gear tables.

## Privacy

There is nothing to sign in to. No accounts, no cookies, no analytics, no
requests to anywhere else — the whole site is static files served by GitHub
Pages. The one thing it remembers is your language choice, stored in your
own browser's local storage. Clearing your site data resets it.

## Run it locally

No build step and no server. Clone the repo and open `index.html` in a browser.

## Contributing

Corrections to skill text or translations are welcome — open an issue with
the skill name and what's wrong.

Note that the skill data file is generated and gets replaced wholesale when
the game updates, so fixes belong in an issue rather than a pull request
against that file.
